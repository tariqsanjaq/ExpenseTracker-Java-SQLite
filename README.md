# Expense Tracker (Android)

Native Android app for managing daily budgets and logging expenses. Built from scratch in Java and XML in Android Studio for the Mobile Applications Development course.

## Screenshots

_Coming soon._

## Features

- Set daily budgets and log expenses
- Data saved locally in SQLite, using a custom database schema
- Input validation with clear feedback messages
- Multi-activity app with navigation between screens using explicit intents

## Tech stack

Java · XML layouts · SQLite · Android Studio

## How to run

1. Clone the repo: `git clone https://github.com/tariqsanjaq/ExpenseTracker-Java-SQLite.git`
2. Open the project in Android Studio
3. Let Gradle sync, then run it on an emulator or an Android device
