# ExpenseTracker-Java-SQLite
A native Android application built with Java and SQLite for personal finance management and budget tracking.

Personal Expense Tracker
A comprehensive mobile application developed to solve realistic financial tracking problems by allowing users to manage daily budgets and log expenditures. Built entirely from scratch using Java and XML in Android Studio , the application demonstrates core mobile architecture concepts and was developed for the Mobile Applications Development course.  Technical Highlights:
* Local Data Persistence: Utilizes a custom SQLite database schema to save local data, handling seamless data retrieval and storage operations.
* Dynamic User Interface: Features a multi-activity architecture utilizing a wide array of Android UI components for a clean, user-friendly interface.
* Activity Lifecycle & Navigation: Implements strict input validation with user feedback messages and handles smooth application flow using explicit intents for internal navigation.
